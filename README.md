# Kyojin gallery

Three open models running on one mini PC, driven by the Hermes agent. Real pages, with the cloud originals at the bottom.

**Open the gallery: https://yamz-labs.github.io/gallery/**

Each prompt is run by the local model with the Hermes agent (tools to write, run and test its page). The vendor's cloud model on the same prompt is shown below for comparison. The last prompt was suggested by a reader. Local runs use an AMD Ryzen AI Max+ 395 mini PC, the [Kyojin](https://github.com/Yamz-Labs/kyojin) engine and the published Yamz packs.

The pages in this repository are written by the models and published as they came out.

First version, more to come. Tell us which prompt to add next in the issues.
