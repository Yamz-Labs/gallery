# Kyojin gallery

Three open models running on one mini PC, next to their cloud originals. Same prompts, real pages.

**Open the gallery: https://yamz-labs.github.io/gallery/**

Each prompt is run three ways: the local model alone, the local model with the Hermes agent (tools to write, run and test its page), and the vendor's cloud model. Local runs use an AMD Ryzen AI Max+ 395 mini PC, the [Kyojin](https://github.com/Yamz-Labs/kyojin) engine and the published Yamz packs.

The pages in this repository are written by the models and published as they came out.

First version, more to come. Tell us which prompt to add next in the issues.
